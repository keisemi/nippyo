# 公開用書誌マスター

`book_search_master.csv` が、この臨時書籍検索システムの唯一の正本です。

通常の書誌追加・修正は、GitHubの

**Actions → 【入力用】書誌データを追加・修正 → Run workflow**

から行います。入力内容はこのCSVへ自動反映され、検索用 `books.js` / `books.json` も自動再生成されます。

通常担当者はこのCSVを直接編集する必要はありません。

元のバックアップCSV、社内用の監査列、内部メモ等は、この公開リポジトリには置かないでください。


`amazon_asin` は任意です。空欄でも検索サイト側がISBN（なければ書名・著者）からAmazon検索リンクを自動生成します。
