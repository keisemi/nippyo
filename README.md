# 日本評論社 臨時ホームページ

通常の日本評論社ウェブサイトのメンテナンス期間中に、必要な情報を継続提供するための臨時サイトです。

## 現在実装済み

- トップページ
- 書籍検索（書名・著者名・ISBN・分野・キーワード）
- 書籍詳細ポップアップ
- Amazon購入導線
- 書誌データからの新刊自動表示
- 書誌追加・修正用 GitHub Issue Form
- 書誌管理用検索ページ
- お知らせ追加・修正・削除用 GitHub Issue Form
- 雑誌ページ（『経済セミナー』note／全記事データベースへのリンクを含む）
- 会社概要・アクセスのページ枠

## データ構造

`data/book_search_master.csv` を書誌の唯一の正本とします。

このCSVから `scripts/build_data.py` が以下を自動生成します。

- `docs/data/books.json`
- `docs/data/books.js`
- `docs/data/home-books.js`（トップページの新刊表示用・軽量）
- `docs/data/admin-books.js`（書誌管理検索用・軽量）
- `docs/data/last-updated.txt`

トップページの新刊、通常の書籍検索、書誌管理用検索は同じマスターCSVを参照します。

## 書誌の更新

### 既存書誌の修正

管理用検索ページを開きます。

`https://keisemi.github.io/nippyo/admin/books/`

1. 書名・著者名・ISBN・書籍IDで対象書を検索
2. 「この書誌を修正」をクリック
3. GitHub Issue Formで変更する項目だけ入力
4. Issueを送信

書籍IDと現在の書名は検索ページから自動入力されます。空欄の項目は変更しません。既存値を消す場合だけ `__CLEAR__` と入力します。

### 新規書誌の登録

管理用検索ページの「新しい書誌を登録」からGitHub Issue Formを開きます。

サイト更新権限のあるCollaborator等からの申請だけが自動反映されます。権限のないアカウントから申請されても書誌データは変更されません。

## お知らせの更新

GitHub の **Issues → New issue →「【入力用】お知らせを追加・修正・削除」** を使います。

- 新規登録：操作で「新規登録」を選び、タイトル等を入力
- 修正：操作で「既存データ修正」を選び、登録済みタイトルをプルダウンから選択
- 削除：操作で「削除」を選び、登録済みタイトルをプルダウンから選択
- 新規登録・修正・削除後、プルダウンのタイトル候補も自動更新

## 書影

将来の書影追加用に `docs/assets/covers/` を用意しています。書籍IDをファイル名にして、たとえば `9827.jpg` のように配置すると、ビルド時に自動認識されます。

## 公開

GitHub Pages は GitHub Actions から `docs/` を公開します。
