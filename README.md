# 日本評論社 臨時ホームページ

通常の日本評論社ウェブサイトのメンテナンス期間中に、必要な情報を継続提供するための臨時サイトです。

## 現在実装済み

- トップページ
- 書籍検索（書名・著者名・ISBN・分野・キーワード）
- 書籍詳細ポップアップ
- Amazon購入導線
- 書誌データからの新刊自動表示
- 書誌追加・修正用 GitHub Actions フォーム
- 雑誌ページ（『経済セミナー』note／全記事データベースへのリンクを含む）
- 会社概要・アクセスのページ枠

## データ構造

`data/book_search_master.csv` を書誌の唯一の正本とします。

このCSVから `scripts/build_data.py` が以下を自動生成します。

- `docs/data/books.json`
- `docs/data/books.js`
- `docs/data/home-books.js`（トップページの新刊表示用・軽量）
- `docs/data/last-updated.txt`

トップページの新刊と書籍検索は同じマスターCSVを参照し、それぞれ用途に応じた自動生成データを使います。

## 書誌の更新

GitHub の `Actions` から **【入力用】書誌データを追加・修正** を実行します。Write権限のあるCollaboratorだけが実行できます。

## 書影

将来の書影追加用に `docs/assets/covers/` を用意しています。書籍IDをファイル名にして、たとえば `9827.jpg` のように配置すると、ビルド時に自動認識されます。

## 公開

GitHub Pages は GitHub Actions から `docs/` を公開します。

## 配色

旧日本評論社サイトで使われていた緑系（濃緑 `#255e17`、黄緑 `#789c18`、淡緑 `#d9e0d8`）を基調にしています。

## お知らせ更新

書き込み権限のある担当者は、GitHub の **Actions →「【入力用】お知らせを追加・修正・削除」→ Run workflow** から更新できます。

- 新規登録：タイトル等を入力して実行
- 修正：現在のお知らせタイトルを「修正・削除する既存タイトル」に入力し、変更したい項目だけ入力
- 削除：現在のお知らせタイトルを指定して削除

HTML・CSV・JSONを通常担当者が直接編集する必要はありません。
