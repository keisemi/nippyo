しっかり身につく「基本シリーズ」の使い方

日本評論社・基本シリーズをいつもご愛顧いただきありがとうございます。

法律を学び始めの人や、司法試験・予備試験の合格を目指す人のために、基本シリーズを用いた効果的な勉強方法について、わかりやすくまとめました。

どこから手に取ればいいか悩んでいる方も、図を見ながら自分のレベルにあった1冊を選んで、そこから始めてみましょう。
