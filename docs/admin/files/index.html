FILES

書籍関連ファイル管理

書籍に付随するファイルや外部リンクを管理するための画面です。立ち読みPDFは書籍・雑誌号の両方をここから管理できます。

書影・正誤表・付属データ・関連リンク・立ち読みPDFの管理機能を利用できます。

COVER

書影

書籍を検索して、書影画像の追加・差替え・削除を行います。

書影管理を開く →

ERRATA

正誤表

書籍を検索して、正誤表PDFの追加・差替え・削除を行います。

正誤表管理を開く →

RELATED FILE

付属データ

解答、追加問題、Excel、プログラムコードなどの付属データを追加・差替え・削除します。

付属データ管理を開く →

EXTERNAL LINK

関連リンク

サポートサイト、動画、記事、イベントページなどの外部リンクを追加・修正・削除します。

関連リンク管理を開く →

PREVIEW PDF

立ち読みPDF

書籍・雑誌号を検索して、詳細ポップアップの書影下に表示する立ち読みPDFを追加・差替え・削除します。

立ち読みPDF管理を開く →
