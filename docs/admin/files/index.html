FILES

書籍関連ファイル管理

書籍に付随するファイルを管理するための画面です。 各機能は順次追加します。

この画面は現在、管理メニューの入口のみ利用できます。
書影・正誤表・付属データの追加、差替え、削除機能は次の工程から1つずつ実装します。

COVER

書影

書籍の書影画像を追加・差替え・削除します。

準備中

ERRATA

正誤表

書籍の正誤表PDFを追加・差替え・削除します。

準備中

RELATED

付属データ

解答、追加問題、Excel、プログラムコードなどの付属データを追加・差替え・削除します。

準備中

日常更新担当者がリポジトリ内のファイルを直接編集しなくても操作できる形に整備します。
